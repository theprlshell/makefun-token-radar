How the radar scores a protocol

Implied value follows only from the snapshot's own figures — TVL, seven-day growth, how long the protocol has run with no token, and how many chains it runs on. No protocol name is ever special-cased.

implied = TVL × sector × (1 + 0.5·tanh(growth ÷ 50)) × (0.7 + 0.3·min(age, 1460) ÷ 1460) × (1 + 0.03·min(chains − 1, 5))

A protocol records no token when DefiLlama's record carries no market cap, no CoinGecko id and no symbol. That is a record, not proof: a protocol on the list may still have a token its record does not carry. The board never ranks exchanges, bridges, liquid-staking products or versioned pools — none of those is a launch. Farm plans are the radar's own suggestion, not financial advice; a claim that asks for a fee or a seed phrase is a scam.
