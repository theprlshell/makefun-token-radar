Token Radar: a static dashboard that ranks every rankable pre-token protocol by an implied value learned from the snapshot's own live-token market data, with a concrete farm plan for each one.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input <snapshot.json>
```
